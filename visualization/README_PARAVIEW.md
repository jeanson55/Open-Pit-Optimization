# ParaView-enabled adaptive solver rewrite

These files preserve the existing optimization workflow while adding an
optional block-level visualization trace.

## Run without visualization

The normal experiment interface remains:

```bash
python experiments/experiment_adaptive_solver.py --dataset bauxitemed --method metis --partitions 9
```

## Run with a trace

```bash
python experiments/experiment_adaptive_solver.py \
  --dataset bauxitemed \
  --method metis \
  --partitions 9 \
  --refinement boundary \
  --export-visualization results/bauxitemed_adaptive_trace.npz
```

This writes:
- `bauxitemed_adaptive_trace.npz`
- `bauxitemed_adaptive_trace.json`

The NPZ contains actual node-level states generated by the solver, including
partition ID, merged/local solution, repair additions, repair level, boundary
membership, boundary additions/removals, and final solution.

## Convert to ParaView VTI

Inside ParaView's Python environment:

```bash
pvpython visualization/paraview_bauxitemed.py \
  results/bauxitemed_adaptive_trace.npz \
  results/bauxitemed_adaptive_trace.vti
```

Then open the `.vti` file in ParaView.
